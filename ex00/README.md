# Shahd Jum'ah - Personal Portfolio

My personal portfolio website, built from scratch at 42 Amman.

## About

A responsive portfolio that presents who I am, my skills, and the projects
I built during my journey at 42 Amman.

## Features

- Sections: Navbar, About Me with photo, Skills, Projects, Contact Form, Footer
- Dark / light theme switcher button
- Responsive design for phones, tablets and laptops

## Technologies

- HTML5
- CSS3 (Flexbox, media queries, CSS variables)
- JavaScript (ES6+)
- Git

## How to run

Open `index.html` in any web browser.

## Theme switcher: how it works

1. The user clicks the theme button
2. A click event fires
3. The `toggleTheme` callback runs
4. It toggles the `dark-mode` class on the body, which changes the CSS variables and the page colors
